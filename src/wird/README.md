# src/wird — الورد اليومي

ui/            واجهة الورد (ما يراه المستخدم)
  text.js        كل نصوص الورد بالعربية والإنجليزية (لغة المشترك: sub.lang، ولغة اللوحة: wird.lang)
  shared.js      دوال مشتركة: التاريخ، النطاقات، نصوص الخطط
  components.js  الأزرار والقوائم وصفوف الأزرار
  cards.js       البطاقات: التذكير، الحالة، الحفظ، التسجيل، الختمة
  notices.js     الإشعارات: الحذف، قرب الانتهاء، الانتهاء، التوقف
  modals.js      النوافذ: الإعدادات، مدة الختمة، صفحات يومياً
  panel.js       لوحة الاشتراك في روم الورد
handlers/      معالجة التفاعلات
  index.js       الموجّه فقط (handleWird)
  subscription.js الاشتراك والإعدادات والحالة والإيقاف والتجديد والحذف
  plan.js        الخطة: المدة، الصفحات اليومية، إعادة الحساب
  shared.js      دوال مشتركة للردود والحراسة

المنطق (utils/wird.js) والخدمة (services/wirdService.js) والقارئ (components/mushafHandler.js) بقيت في أماكنها.
utils/wirdUi.js و components/wirdHandler.js مجرد واجهات تحويل حتى لا ينكسر أي استيراد قديم.
