## 🚀 التركيب

### 1. تثبيت
```bash
npm install
```
> **لا يحتاج Lavalink.** البوت يشغّل الصوت مباشرة عبر `ffmpeg` + `@discordjs/voice`.
> يتم اكتشاف ffmpeg تلقائياً (متغير `FFMPEG_PATH` ← ffmpeg المثبّت على النظام ← `ffmpeg-static`).
> ترميز الصوت يتم عبر `opusscript` (JavaScript خالص، بدون تجميع). لو سيرفرك ضعيف الـ CPU ويشغّل جلسات كثيرة،
> يمكنك تثبيت `@discordjs/opus` يدوياً (أسرع) — لكنه يسحب أداة `tar` ذات ثغرات معروفة وقت التثبيت.

### 2. إعداد .env
```bash
cp .env.example .env
# عدّل الملف بالقيم الحقيقية
```

### 3. تسجيل الأوامر
```bash
npm run deploy
```

### 4. تشغيل البوت
```bash
npm start
```

## 🌐 إعداد الـ Dashboard

### Discord OAuth2
في https://discord.com/developers/applications:
1. افتح تطبيقك ← OAuth2
2. أضف Redirect URI: `https://api.YOUR_DOMAIN.com/auth/discord/callback`
3. انسخ Client Secret إلى `.env`

### لوحة المالك
لا يوجد موقع عام: اللوحة الوحيدة تُخدَّم من نفس سيرفر البوت على `API_BASE_URL/admin`، وتحتاج رابطاً واحداً فقط.
- ضع في `.env`: `API_BASE_URL=https://YOUR_DOMAIN.com` و`ADMIN_IDS=<معرّف حسابك>`.
- افتح `https://YOUR_DOMAIN.com/admin` وسجّل الدخول بـ Discord. أي حساب غير المحدد في `ADMIN_IDS` يُرفض ولا تُنشأ له جلسة.
- لو استضفت ملفات اللوحة على نطاق آخر ضع `ADMIN_DASHBOARD_URL` برابطه.

## 📖 آية اليوم · 🌙 الورد اليومي

### آية اليوم
آية مع **التفسير الميسر** تُنشر يومياً في **روم مخصص** (منفصل عن روم الأذكار) وبنفس لوحة الأذكار:
`/setup` ← **آية اليوم** ← اختر الروم والوقت ورتبة المنشن ← **تفعيل**.
- نص الآية والتفسير يُجلبان من API القرآن وقت النشر (لا نصوص مكتوبة يدوياً)، ويُتحقق من رقم الآية قبل النشر؛ وإن تعذّر الجلب يُعاد المحاولة تلقائياً خلال ساعتين.
- الآية نفسها لكل السيرفرات في نفس التاريخ، وتتغير يومياً من قائمة منتقاة في `src/data/ayahs.js`.
- متغيرات اختيارية: `AYAH_API_URL`, `AYAH_TEXT_EDITION`, `AYAH_TAFSIR_EDITION`, `AYAH_API_TIMEOUT_MS`.

### الورد اليومي ومتابعة الختمة (اشتراك شهري مجاني)
| الأمر | الوصف |
|-------|-------|
| `/wird setup channel:#الروم [language] [announce]` | (إدارة السيرفر) ينشر لوحة الاشتراك في روم الورد بالعربية أو English، ويحدد مكان الإعلانات والتذكير الاحتياطي. لغة اللوحة هي لغة المشتركين الجدد |
| `/wird start` | اشتراك مجاني (أو الاستئناف) |
| `/wird me` | تقدّمي، سلسلتي، وموعد انتهاء الاشتراك |
| `/wird stop` | إيقاف التذكيرات (التقدم يبقى محفوظاً) |
| `/wird delete` | حذف بياناتك نهائياً (بعد تأكيد) |

- **الاشتراك**: 30 يوماً مجاناً؛ قبل الانتهاء بـ3 أيام يصل تنبيه بزر «جدّد»، وعند الانتهاء تتوقف التذكيرات ويبقى التقدم. الاشتراك **لا يمتد تلقائياً** حتى لو سجّل العضو وردّه: يتوقف البوت عند انتهائه ولا يستمر حتى انتهاء الختمة، والتجديد بضغطة مجانية. وفي الوضع الافتراضي يتبدّل وقت التذكير يومياً بين الصباح والعصر والمساء (ولكل عضو دقيقة مختلفة) فلا تصل التذكيرات للجميع معاً، ويستطيع العضو تحديد وقت ثابت بدلاً منه. وإذا لم يسجّل العضو شيئاً لمدة 7 أيام تتوقف التذكيرات تلقائياً مع رسالة «استأنف الورد».
- **التذكير**: يصل على الخاص بتوقيت العضو (يقبل اسم البلد بالعربي)، وإن كان الخاص مغلقاً يُمنشَن في روم الورد. لا يُرسَل لمن أتمّ وردَه اليوم.
- **المتابعة**: صفحات اليوم (من–إلى) مع السورة والجزء ورابط للقراءة، شريط تقدم، سلسلة أيام، تقدير تاريخ الختم، وعدد الختمات. عند بلوغ الصفحة 604 تُسجَّل ختمة وتبدأ أخرى تلقائياً مع إعلان اختياري في الروم.
- بعد التحديث شغّل `npm run deploy` (أو أعد تشغيل البوت فالنشر التلقائي للأوامر مفعّل).

## هدف الختمة والفعاليات الدينية

- **تغيير الخطة بسهولة:** بطاقة `/wird me` فيها قائمتان منسدلتان تتحدث البطاقة نفسها عند الاختيار: **مدة الختمة** (15 يوماً، شهر، شهران، 3 أشهر، 6 أشهر، أو «مدة أخرى» من 7 إلى 365 يوماً فيحسب البوت الصفحات)، و**صفحاتي اليومية** (1، 2، 5، 10، 20 أو «عدد آخر» تكتبه بنفسك بلا حساب). الخيار الحالي يظهر محدداً، وإن تأخر العضو عن مدته يظهر زر «أعد حساب خطتي».
- **زر «وقت التذكير والمنطقة»** يعدّل الوقت والبلد وآخر صفحة دون المساس بالخطة.
- **الفعاليات الدينية** (للمشرفين، صلاحية إدارة السيرفر): `/events add` لفعالية مرة واحدة أو يومية بين تاريخين، `/events list` و`/events test` و`/events remove`.
  مثال لرمضان: `/events add title:تحدي ختمة رمضان time:21:00 start:2027-02-08 end:2027-03-09 channel:#رمضان`.
- بعد التحديث شغّل `npm run deploy` لتسجيل الأمر الجديد `/events`.

## نشر الأوامر في مكان واحد + الفرق بين Panel و Dashboard

- **مكان واحد للأوامر** (`DEPLOY_SCOPE` في `.env`): `global` (الافتراضي، كل السيرفرات) أو `guild` (السيرفر الأم `GUILD_ID` فقط، وتحديث فوري). النشر التلقائي عند التشغيل و`npm run deploy` يحذفان النسخة الأخرى تلقائيًا فلا تتكرر الأوامر.
  - `npm run deploy:mother` — السيرفر الأم فقط (يُفرغ الأوامر العامة). `npm run deploy:global` — كل السيرفرات (يحذف نسخة السيرفر الأم).
  - `npm run deploy:check` — فحص فقط (لا يغيّر شيئًا): كم أمرًا مسجّلاً عامًا وكم في السيرفر الأم، وأي أمر يظهر مرتين.
  - الأوامر تُرسل بترتيب ثابت حسب الأقسام (`src/data/commandOrder.js`، نفس ترتيب `/help`)، وإعادة التشغيل دون تغيير لا ترسل شيئًا. أمر جديد يجب إضافته للقائمة وإلا يفشل الاختبار.
  - إن كان عندك **بوت ثانٍ** بنفس الكود (`ALT_BOT_ID`) فأوامره تظهر بجانب أوامر الأول في نفس السيرفر وهذا طبيعي في ديسكورد (لكل بوت أيقونته)؛ لا يمكن للكود إخفاؤها.
- **القرآن كاملاً:** `/khatma reciter:<قارئ> [from:<رقم السورة>]` — يشغّل 114 سورة بالترتيب دون توقف، ويمكن البدء من أي سورة.
- **Panel ≠ Dashboard:** `/panel` و`/start` = لوحة التشغيل بالأزرار داخل ديسكورد (لكل المستخدمين). الداشبورد = صفحة ويب `/admin` لمالك البوت والمشرفين فقط.

## تطوير الأذكار والأدعية والورد (قراءة بالاشتراك)

- **أذكار الصباح والمساء في الخاص (اختياري):** من `/wird me` زرّان: 🌅 أذكار الصباح و🌙 أذكار المساء. تصل نسخة مختصرة على الخاص بتوقيت العضو نفسه (06:00 و17:00 افتراضيًا)، ضمن نفس الاشتراك المجاني (30 يومًا). لا تُرسل أبدًا في روم عام، وإن كان الخاص مغلقًا تُطفأ تلقائيًا. العضو الذي فعّلها لا يُوقَف بسبب عدم قراءة الصفحات (يتوقف تذكير الصفحات فقط).
- **أذكار وأدعية جديدة (منشورات اليوم):** قبل النوم (آية الكرسي، آخر آيتين من البقرة، المعوذات، أسلمت نفسي)، بعد الصلاة (الاستغفار، اللهم أنت السلام، التسبيح، آية الكرسي)، ويوم الجمعة فقط (الصلاة على النبي، سورة الكهف). وأذكار المساء الكاملة صارت تضم آخر آيتين من البقرة. **راجع النصوص على مصدرك الموثوق (مثل حصن المسلم) قبل النشر.**
- **الجمعة في الورد:** تذكير الورد وصفحة الخاص يوم الجمعة يضيفان تنبيه سورة الكهف (الصفحات 293–304) والصلاة على النبي ﷺ.
- **دعاء الختمة:** بطاقة إتمام الختمة صارت تحمل أدعية للقرآن وللقبول (بالعربية والإنجليزية).

## التعرف على بلد العضو / مدينته (المنطقة الزمنية)

كان التعرف يعتمد على جدول يدوي قصير بأسماء مطابقة تمامًا. الآن (`src/utils/timezoneResolver.js` + `src/data/countries.js`):
- **كل الدول** (246) بالعربية والإنجليزية والفرنسية ورمز الدولة، ومئات المدن (ولايات الجزائر، مدن المغرب ومصر والسعودية…، ومدن المهجر الكبرى).
- يتجاهل الهمزة والتاء المربوطة وأل التعريف والتشكيل والحركات الفرنسية: «الإمارات» = «الامارات»، «Algérie» = «algerie».
- يفهم الكلام الزائد: «جمهورية مصر العربية»، «i live in الجزائر».
- يتسامح مع **خطأ إملائي واحد** فقط إذا كان لا يحتمل إلا مكانًا واحدًا (`Saudy Arabia`، `الجزاير`)، ولا يخمّن بين مكانين.
- يقبل فرق التوقيت: `UTC+1`، `GMT-5`.
- إن لم يتعرف يقترح: «هل تقصد: الجزائر؟».
